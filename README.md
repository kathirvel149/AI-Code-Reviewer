# 🤖 AI Code Reviewer

An automated Python code analysis tool built using Streamlit.

## 📌 About the Project

AI Code Reviewer analyzes uploaded Python files and provides useful information about code quality, formatting, complexity, security vulnerabilities, and code metrics.

## 🚀 Features

* 🔍 **Flake8 Analysis** – Detects Python coding-style issues
* 🖤 **Black Formatter** – Formats Python code automatically
* 🧠 **Radon Complexity** – Measures code complexity
* 🔐 **Security Scanner** – Detects basic security vulnerabilities
* 🛡️ **Advanced Security Checks** – Checks for SQL Injection and Command Injection patterns
* 🏆 **Code Quality Score** – Calculates an overall score out of 100
* 📊 **Code Metrics** – Displays lines, functions, classes, and comments
* ❤️ **Code Health** – Shows the overall health of the uploaded code
* 🤖 **Smart Suggestions** – Provides improvement suggestions
* 📥 **Download Formatted Code** – Downloads the formatted Python file
* 📄 **Download Review Report** – Downloads a complete code review report

## 🛠️ Technologies Used

* Python
* Streamlit
* Flake8

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project folder

```bash
cd AI-Code-Reviewer
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install streamlit flake8 black radon
```

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
